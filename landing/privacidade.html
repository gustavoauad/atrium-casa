Política de Privacidade

Última atualização: 18 de julho de 2026 · Versão 1.0

Esta Política explica como o Atrium Casa trata dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD). O Aplicativo lida com dois grupos de dados pessoais: (1) os seus dados, como Usuário titular de conta; e (2) os dados de terceiros — seus funcionários domésticos — que você mesmo insere para gerar a folha de pagamento.

1. Quem trata os dados

O Atrium Casa é o Controlador dos dados pessoais dos Usuários (titulares de conta) para as finalidades de operação da plataforma, cobrança e suporte. Em relação aos dados de funcionários domésticos inseridos pelo Usuário, o Atrium Casa atua como Operador: processa esses dados exclusivamente conforme as instruções e para as finalidades definidas pelo próprio Usuário, que é o Controlador desses dados perante seus empregados.

3. Base legal para o tratamento

  • Execução de contrato: para viabilizar o cadastro, login e uso das funcionalidades do Aplicativo pelo Usuário;
  • Legítimo interesse: para melhorias do Serviço, prevenção a fraudes e segurança;
  • Cumprimento de obrigação legal/regulatória: quando aplicável, para fins fiscais e de faturamento;
  • Dados de funcionários domésticos: tratados pelo Atrium Casa como Operador, conforme a base legal que o próprio Usuário (Controlador/empregador) possui para tratar os dados de seus empregados — tipicamente execução de contrato de trabalho e cumprimento de obrigação legal (LC 150/2015).

4. Para que usamos os dados

  • Viabilizar o cálculo de folha de pagamento, encargos e verbas rescisórias solicitados pelo Usuário;
  • Autenticação, gestão de conta e de acesso multi-usuário por Casa;
  • Processar pagamentos de assinatura (via Stripe);
  • Enviar comunicações operacionais (confirmações, avisos de cobrança, recuperação de senha);
  • Suporte ao Usuário e melhoria contínua do produto.

Não utilizamos os dados de funcionários domésticos para nenhuma outra finalidade além de viabilizar as funcionalidades do Aplicativo solicitadas pelo Usuário, e não os compartilhamos com terceiros para fins de marketing ou publicidade.

5. Com quem compartilhamos dados

TerceiroFinalidade

StripeProcessamento de pagamentos de assinatura

Não vendemos dados pessoais a terceiros. Podemos divulgar dados quando exigido por lei, ordem judicial ou autoridade competente.

6. Armazenamento e segurança

Os dados são armazenados em servidores do Supabase, com controles de acesso baseados em autenticação e regras de segurança em nível de linha (Row-Level Security), garantindo que cada Usuário só acesse os dados das Casas às quais pertence. Nenhum sistema é 100% livre de riscos; adotamos medidas técnicas e organizacionais razoáveis para proteger os dados, mas não podemos garantir segurança absoluta.

7. Retenção e exclusão

Mantemos os dados enquanto a conta estiver ativa e pelo tempo necessário para cumprir finalidades legais, contratuais ou regulatórias (por exemplo, obrigações trabalhistas que recomendam guarda de registros por até 5 anos). O Usuário pode solicitar a exclusão de sua conta e dos dados associados a qualquer momento, ressalvadas as hipóteses de guarda obrigatória por lei.

8. Direitos do titular de dados (LGPD, art. 18)

Você pode, a qualquer momento, solicitar:

  • Confirmação da existência de tratamento e acesso aos seus dados;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei;
  • Portabilidade dos dados a outro fornecedor de serviço;
  • Eliminação dos dados tratados com consentimento, quando aplicável;
  • Informação sobre entidades com as quais compartilhamos dados;
  • Revogação do consentimento, quando esta for a base legal aplicável.

Solicitações podem ser feitas por contato@atrium-casa.com. Quando a solicitação envolver dados de um funcionário doméstico, orientaremos o titular a contatar diretamente o Usuário (seu empregador), que é o Controlador responsável por esses dados.

9. Dados de crianças e adolescentes

O Aplicativo não se destina a menores de 18 anos como titulares de conta. Dados de funcionários domésticos cadastrados seguem as regras normais de tratamento de dados de trabalhadores.

10. Alterações desta Política

Podemos atualizar esta Política periodicamente. Alterações relevantes serão comunicadas dentro do Aplicativo.

11. Contato / Encarregado de Dados

Para exercer seus direitos ou esclarecer dúvidas sobre esta Política, entre em contato: contato@atrium-casa.com.
